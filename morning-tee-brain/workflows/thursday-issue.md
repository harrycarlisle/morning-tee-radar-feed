# Thursday Issue Workflow

Thursday is for setup: what to watch, why it matters, and how to understand the golf before the weekend.

1. Check official field, tee times, course notes, weather, and current news.
2. Build a short candidate list of course-fit and player-trend angles.
3. Pick one main watch item.
4. Add one secondary tour note or player trend.
5. Add one useful tip/rules/shot section.
6. Keep previews specific. Avoid generic "players to watch" filler.
7. Add source notes and open verification items.
8. Run the production checklist.
9. Human reviews and manually moves final copy into Beehiiv.

Thursday issue bias:
- Course fit.
- Skills the week will reward.
- Strategic questions.
- Player trends that are easy to watch.
- One thing that will make the weekend more interesting.
